# notebooks/

Jupyter Notebook untuk analisis eksploratif (Tahap 3+: visualisasi grafik Bab IV,
uji sensitivitas, eksplorasi neraca air).

- Notebook yang bersifat eksploratif boleh memakai `data/sample/` atau
  `data/processed/hidrologi.db`.
- Hasil yang akan dipakai di naskah TIDAK dibuat di notebook saja — harus lewat
  skrip di `src/`/`tools/` agar bisa diverifikasi ulang (lihat `README.md` root).
- Jangan commit output notebook besar (.ipynb_checkpoints sudah di-ignore).
